## [0.1.0] - unreleased

### Added

- eBUS heating devices (Vaillant, Saunier Duval, AWB, Bulex, Wolf, Kromschröder…) read through an ebusd daemon of the local network, over its TCP port (8888 by default), with the optional user and secret of an ebusd access file.
- One Gladys device per eBUS circuit ebusd knows (boiler, heat pump, controller, heating circuit, broadcast…), named after the model it announces, plus ebusd itself with the eBUS signal.
- Features chosen among the values ebusd has seen on the bus (temperatures, pressure, flame, modulation, power, energy, hours, starts, modes, current error) and the well-known messages of Vaillant installations, with names in English, French, German or Spanish; every value ebusd has seen on request, and any message listed in the settings.
- Values pushed live by ebusd as they change on the bus, the others read every 1 to 10 minutes from the memory of ebusd when recent enough, from the bus otherwise.
- Changes off by default: once allowed, room targets (5 to 30 °C), hot water target (35 to 70 °C), on/off and operating modes that the controller opens to everyone, never the installer or service settings; a value already set is never written again, one message at most once a minute, 100 changes a day at most, read back after writing.
- Dashboard widgets "Heating" (outdoor, flow, return, room and hot water temperatures, pressure, flame, modes, error), "Heating curves" (over 1, 3 or 7 days) and "eBUS" (signal, traffic, devices seen with their model and software).
- Scene triggers: an eBUS device reports an error code, the error is cleared, ebusd stops answering, ebusd answers again.
- Scene actions: read any ebusd message (value, number, unit, every field) and write a message open to everyone when changes are allowed.
- Configuration button "Test ebusd and search the devices".
